# PillPath — Interactive Prototype Source Code

This is the complete browser-based source for the PillPath medication reminder demonstration, including the latest 3D case and live timer updates.

## Run it locally

1. Unzip the archive.
2. Open `index.html` in Chrome, Safari, Edge, or Firefox.
3. Click **Trigger reminder** for an instant demo, or **20s countdown** to show the live case timer.
4. Click the 3D case to confirm the dose and clear the simulated phone notification.

No installation, dependencies, API keys, or build commands are required.

## Files

- `index.html` — app structure, case model, and companion phone interface.
- `styles.css` — visual design, CSS 3D geometry, responsiveness, and animations.
- `app.js` — reminders, countdown, live clock, case rotation, and dose confirmation.

## Important

This is a demonstration prototype. The phone notification is simulated inside the web page, and the 3D case is rendered with HTML/CSS transforms. No physical device, Bluetooth connection, server, or real medication data is connected.
